# 使用说明

## 运行服务

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r server\requirements.txt
uvicorn app.main:app --reload --port 8765 --app-dir server
```

服务默认监听 `http://127.0.0.1:8765`。

## 安装插件

1. 打开 Chrome `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目里的 `extension/`。
5. 打开招聘页面，点插件图标或侧边栏开始使用。

## 推荐工作流

1. 在侧边栏粘贴或上传简历文本。
2. 点击“生成规则”。
3. 打开目标招聘网页。
4. 选择扫描模式，并按需要调整 Top N、最大页数、最大岗位数、补详情数和候选上限。
5. 点击“扫描当前网页”。
6. 如果页面要求登录，手动登录后点击“继续扫描”。
7. 用“全部 / 推荐 / 可考虑 / 不建议”筛选结果，点击岗位详情进入原页面投递。
8. 对值得跟进的岗位点击“加入岗位库”，或批量保存当前筛选结果。
9. 在岗位库里维护状态、优先级、备注、标签、截止时间、下一步动作日期，并导出 CSV 复盘。

## 扫描模式

- `快速`：少量分页和详情补抓，适合先判断页面是否有岗位。
- `均衡`：默认模式，兼顾速度、详情完整度和 Claude 成本。
- `深度`：扩大分页、岗位数、详情补抓和候选上限，适合正式筛一批大型招聘站。

`候选上限` 控制进入 Claude 精排前的候选数量。数量越大，分析更充分，但耗时和成本也会增加。

## 结果与诊断

推荐结果会显示：

- 推荐等级：推荐、可考虑、不建议。
- 匹配分数和理由。
- 风险点和缺失技能。
- 详情链接状态：已捕获真实详情链接，或需要回到列表页自动定位。
- 生成材料包：调用本地 Claude/API，根据简历和岗位详情生成投递备注、简历突出点、风险补强和面试准备清单。

扫描诊断会优先展示摘要，包括列表抽取次数、详情补抓成功数、分页/滚动次数和排序诊断数；展开后可查看原始 JSON trace。

## 岗位库

岗位库用于沉淀筛选后的候选岗位，避免每次扫描后结果丢失。

支持：

- 加入岗位库。
- 批量保存当前筛选结果。
- 搜索岗位、公司、标签和备注。
- 按状态筛选，并按优先级、截止时间、下一步动作、匹配分、保存时间排序。
- 标记状态：收藏、准备投递、已投递、面试中、放弃。
- 维护优先级、标签、截止时间、下一步动作日期和备注。
- 查看近期动作和逾期项统计。
- 复制单个岗位分析摘要。
- 从推荐结果或岗位库一键生成投递材料包，并复制到剪贴板。
- 从岗位库复制兜底 Prompt，用于 Claude 不可用时手动生成定制建议。
- 打开原岗位链接。
- 移除岗位。
- 导出 CSV 复盘。

## 模型策略

大模型只负责高价值步骤：

- 简历生成匹配规则。
- 复杂页面结构化抽取兜底。
- 候选岗位最终精排。
- 单个岗位投递材料包生成。

大量岗位的初筛由本地程序执行，但规则来源是大模型。

## 接入本地 Claude

服务默认会优先调用本机 `claude` 命令做最终岗位精排。确认方式：

```powershell
claude --version
```

可选配置：

```powershell
$env:AI_JOB_JUDGE_RANKER_PROVIDER="claude"
$env:AI_JOB_JUDGE_CLAUDE_MODEL=""
$env:AI_JOB_JUDGE_CLAUDE_TIMEOUT_SECONDS="180"
$env:AI_JOB_JUDGE_CLAUDE_MAX_BUDGET_USD="0.5"
```

排序优先级：

1. `claude`：通过 Claude Code CLI 非交互模式返回 JSON。
2. `llm`：OpenAI-compatible API。
3. `heuristic`：本地启发式兜底。

插件扫描完成后会显示本次排序来源。
